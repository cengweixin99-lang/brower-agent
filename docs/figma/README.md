**当前覆盖范围为部分完成。** 已保存 5 个画板、1275 个节点的几何、样式、文本和矢量路径，以及 42 条交互动作。文件共有 51 个顶层画板；浏览器会话整页和其余 45 个状态原型目前只有清单，精确属性及出边尚未取得。Figma MCP 返回 Starter 计划调用额度限制，因此这些内容不得按“已核实设计”实现。

每份画板 JSON 包含 `nodes` 和去重后的 `styles`。节点的 `s` 是该文件的样式索引，`styles[node.s]` 即节点属性。文本 `segments` 的每项是 `[start, end, styleIndex]`，对应文本区间及字体样式。数组顺序保留源图层遍历顺序；`parentId` 保留层级。

`box` 是相对父节点的 `[x, y, width, height]`；顶层画板的 x、y 是 Figma 画布位置，不是网页定位。正文表格特别注明坐标原点。数值汇总将浮点误差显示为 145%、150 ms 等；JSON 保留接口原值。没有导出字体文件、组件来源映射、完整变量定义或所有 Plugin API 属性。

## 已核实的交互流程

原型入口是 `8:235`，名为 Browse Agent · Complete task flow。下列目标若尚未捕获，只表示入边已确认，不表示目标页后续行为也已确认。

| 来源                     | 触发                               | 目标                              | 转场                      |
| ------------------------ | ---------------------------------- | --------------------------------- | ------------------------- |
| 空任务页 `8:235`         | 点击输入框、任一模板或 Run Task    | 已填任务页 `5:2`                  | Dissolve，Ease Out，150ms |
| 空任务页 `8:235`         | Enter，键码 [13]                   | 已填任务页 `5:2`                  | Dissolve，Ease Out，150ms |
| 已填任务页 `5:2`         | 点击 Run Task                      | Thinking `8:348`                  | Dissolve，Ease Out，150ms |
| 已填任务页 `5:2`         | 键码 [91,13]，对应示例中的 ⌘ Enter | Thinking `8:348`                  | 无转场                    |
| 空任务页或已填任务页     | 点击当前研究任务 / 返回当前任务    | 工作区 `5:5`                      | 无转场                    |
| 工作区 `5:5`             | 点击 Pause                         | Paused / Agent workspace `8:2325` | Dissolve，Ease Out，150ms |
| 工作区 `5:5`             | 点击 Stop                          | Stopped `8:3792`                  | Dissolve，Ease Out，150ms |
| 工作区 `5:5`             | 12 秒后                            | Awaiting approval `8:3072`        | Dissolve，Ease Out，150ms |
| 工作区 `5:5`             | 点击 Asana 标签                    | Tool call / Asana `8:1095`        | Dissolve，Ease Out，120ms |
| 工作区 `5:5`             | 点击 Notion 标签                   | Tool call / Notion `8:1335`       | Dissolve，Ease Out，120ms |
| 已捕获的新任务页或工作区 | All Tasks / Recent Tasks / History | 历史页 `5:8`                      | 无转场                    |
| 历史页 `5:8`             | 点击运行中的研究任务行             | 工作区 `5:5`                      | 无转场                    |
| 历史页 `5:8`             | New Task                           | 空任务页 `8:235`                  | 无转场                    |
| 已捕获页面的会话导航     | Browser Sessions                   | 会话页 `8:5552`                   | 无转场                    |
| 沙盒卡片                 | Resume session / Stop session      | Connected / Stopped 变体          | Dissolve，Ease Out，120ms |

重要差异：空任务原型的 Run Task 只是进入已填示例页；已填页的 Run Task 才进入 Thinking。不能把这两条连线误读为同一事件。工作区的 12 秒超时是原型演示机制；生产任务状态应由执行事件驱动，不应固定 12 秒进入审批。

已捕获的多数 NAVIGATE 动作设置 `resetScrollPosition: true`，具体以 interactions.json 中每条 action 为准。工具返回同时包含单数 `action` 与数组 `actions`；交互索引按 `actions` 展开一次，避免重复统计。

## 待补齐的设计内容

[manifest.json](manifest.json) 中不在 `capturedFrameIds` 内的 46 个画板均待读取。下一轮优先顺序：

1. 浏览器会话整页 `8:5552`：主卡片、标签页、连接信息、创建与管理入口。
2. 审批 `8:3072`、已发布 `8:3312`、本地保留 `8:3552`、停止 `8:3792`：确认每个操作的目标、结果及退出路径。
3. Thinking `8:348`、Searching `8:597`、Browsing `8:846`、Asana `8:1095`、Notion `8:1335`：阶段变化与真实连线。
4. 六个暂停画板：核对 Resume 的对应恢复目标，避免恢复到错误阶段。
5. History / Sessions 的 30 个状态变体：核对任务阶段、状态标记及返回当前任务的目标是否保持一致。

画板名称表明存在思考、搜索、浏览、工具调用、暂停、审批、本地完成、已发布、停止等状态，但仅凭命名不能确定它们的全部流转顺序。审批按钮的文字、审批与本地保留分支、完成结果操作尚不能从已保存数据核实。

## 前端实现约定建议

以下是基于当前仓库和已读设计的实现建议，不是新增的 Figma 属性。

将共用布局拆为 AppShell、Sidebar、PageHeader；将业务区域拆为 TaskComposer、AgentActivity、BrowserPreview、TaskHistoryTable、ExecutionDetails、BrowserSessionCard，并共享 Button 和 StatusBadge。保持任务阶段、任务状态、当前浏览器标签、当前页面和结果发布状态分别建模，避免将 51 张演示画板直接转换为 51 条业务路由。

以 1440 × 1000 为首个视觉验收尺寸。通过 flex/grid 表达侧栏、双列面板和卡片关系；调整窗口宽度时的行为、键盘焦点、空列表、加载、错误和无权限状态均需补充，不能从当前固定坐标设计中推定。

先实现可控的本地演示状态，再对接任务 API；不把原型示例里的模型名、定价、任务数量、进度百分比和时长当作线上事实。浏览器执行继续经过 browser-worker gateway；页面只能发出任务意图，不能绕过网关直接执行浏览器操作。Temporal 的 I/O 仍放在 activities 中。

## 数据校验范围

设计采集阶段已校验 JSON 可解析、节点数与清单一致、父子引用与样式索引有效、文本区间合法，并核对交互索引与原始 reactions 一致。Figma 设计文件未被修改。

## 本地交互原型

`apps/web` 已按当前已捕获参数实现新任务、执行工作区和历史页，并沿用相同视觉规范补充浏览器会话、审批、完成、停止及弹窗。补充状态和响应式布局属于本地原型设计，尚未与剩余 Figma 画板逐项核对。

使用 Node 24、pnpm 11.25.0，运行 `pnpm install --ignore-scripts` 后执行 `pnpm dev:web`，访问 `http://127.0.0.1:5173/`。字体为本地 Geist，图标 SVG 从已保存的 Figma 矢量路径生成；字体许可证位于 `apps/web/public/fonts/OFL.txt`。

可点击模板填入任务，运行后每 4 秒进入下一演示阶段；暂停保持阶段，恢复继续，停止终止流转。审批可选择模拟发布或本地保留，完成后可导出示例 CSV。历史页支持搜索、状态和日期筛选、分页、详情；会话页支持创建和启停演示会话。设置、帮助与窄屏菜单也可操作。

所有任务、会话、偏好和附件名称仅保留在页面内存中，刷新即重置。附件内容不会上传；模型选择、浏览器网页、DOM 视图、截图视图和发布操作均为演示，不调用付费模型、任务 API 或外部服务。Scheduled Tasks 暂为入口空状态。正式接入时仍须遵守 browser-worker gateway 和 Temporal activities 的边界。

状态测试：`node --test apps/web/src/task-model.test.ts`。仓库检查：`pnpm check`。生产构建：`pnpm --filter @pba/web exec vite build`。页面已在 1440 × 1000 和 390 × 844 下通过浏览器检查；预览截图保存在被 Git 忽略的 `.data/screenshots/`。
